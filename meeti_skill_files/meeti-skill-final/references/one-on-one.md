# 1:1 Meeting Notes

## Key Focus Areas

1:1s emphasize personal development, feedback exchange, and relationship building. Prioritize:
- Career development discussions
- Feedback (given and received)
- Support needs and blockers
- Goals and growth opportunities

## Additional Sections for 1:1s

After the standard output structure, add:

### Career Development
Summarize any discussion of:
- Career goals and aspirations
- Skill development areas
- Role progression or promotions
- Projects for growth/visibility

### Feedback Checklist

| Category | Details |
|----------|---------|
| **Feedback Given** | [What the manager/senior shared] |
| **Feedback Received** | [What the report/junior shared] |
| **Growth Opportunities** | [Areas identified for development] |
| **Support Needed** | [Resources, help, or changes requested] |

If any category has no content, write "None discussed" rather than omitting.

## Example Output Snippet

```
### Career Development
Alex expressed interest in moving toward a tech lead role within 18 months. Discussion focused on gaining more cross-team visibility through the upcoming API redesign project.

### Feedback Checklist

| Category | Details |
|----------|---------|
| **Feedback Given** | Strong technical work on auth service; need to improve documentation habits |
| **Feedback Received** | Requests more context on roadmap decisions; appreciates autonomy on implementation |
| **Growth Opportunities** | Leading a small project end-to-end; presenting at team demos |
| **Support Needed** | Time allocation for learning Kubernetes; pairing with DevOps team |
```

## Common 1:1 Improvement Tips

- Schedule recurring 1:1s and protect the time
- Maintain a shared running doc for topics
- Alternate between tactical and strategic discussions
- Follow up on previous action items at the start
